## Project

This is a FastAPI backend learning project built as a production-style application.
The project uses feature-oriented organization.

## Stack

- Python 3.13
- FastAPI
- Pydantic v2
- SQLAlchemy 2.x async
- asyncpg
- PostgreSQL
- Alembic
- pytest
- uv

## Architecture

- Keep the project feature-oriented.
- Routers own HTTP concerns.
- Services own business logic and transaction orchestration.
- Repositories own database queries.
- Do not raise FastAPI HTTPException from services or repositories.
- Avoid adding abstraction layers without a concrete responsibility.

## Database

- Use SQLAlchemy 2.x APIs.
- Use AsyncSession for database access.
- Database schema changes require Alembic migrations.
- Review autogenerated migrations before applying them.
- Do not manually modify production schema outside migrations.

## Security

- Never store plaintext passwords.
- Never commit secrets or .env files.
- Do not expose password hashes in API responses.
- Do not weaken authentication or authorization to make tests pass.

## Working Agreement

Before changing code:

- Inspect relevant existing code first.
- Follow existing conventions unless there is a concrete reason not to.

When implementing:

- Make the smallest change that fully satisfies the task.
- Do not refactor unrelated code.
- Do not add dependencies unless required.

After changing code:

- Run focused tests first.
- Report changed files and important decisions.
- Report real failures instead of hiding or bypassing them.
